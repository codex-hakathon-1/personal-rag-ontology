## Codex

현재 이 작업 공간에는 `memory.md`가 없고, 내가 자동으로 생성·기록하는 규칙도 없습니다. 사용자가 “기억해줘/저장해줘”라고 요청하거나, 적용 중인 지시·스킬이 명시할 때만 파일 메모리를 씁니다.

저장 기준은 이렇습니다.

- 다음 작업에도 유효한 사용자 선호, 프로젝트 불변 조건, 확정된 결정
- 반복 작업에 필요한 상태·절차
- 모르면 다시 시간/오류가 큰 비자명한 주의사항
- 출처가 분명하고, 짧고 검증 가능한 사실

저장하지 않는 쪽:

- 일회성 대화 요약, 임시 진행상황, 추측
- 쉽게 다시 확인 가능한 정보
- 비밀번호·API 키·불필요한 개인정보
- 유효기간이 짧은 사실(가격, 일정, 최신 버전 등) — 꼭 필요하면 날짜·출처를 함께 기록

꺼내 쓰는 기준도 “현재 요청과 관련 있는가”입니다. 작업 시작 시 관련 항목만 읽고, 요구사항·제약·반복 절차에 영향을 줄 때만 반영합니다. 다만 메모리는 보조 자료라서, 사용자의 최신 지시·프로젝트 규칙·원본 데이터와 충돌하면 항상 그것들이 우선입니다. 오래됐거나 변동 가능한 내용은 다시 확인합니다.

원하면 앞으로 적용할 `memory.md`의 저장 형식과 갱신 규칙을 함께 정해둘 수 있습니다.

## Codex

맞아요. Codex 기본 규약에 `memory.md`라는 특별 파일은 없습니다.

`memory.md`는 팀이나 사용자가 정하는 관례일 뿐입니다. 만들어도 Codex가 파일명만 보고 자동으로 매 작업마다 읽지는 않습니다. 자동 적용이 필요하면 `AGENTS.md`에 “작업 시작 시 `memory.md`를 읽고, 확정된 장기 정보만 갱신”처럼 명시해야 합니다.

현재 환경에도 `memory.md`는 없었습니다. 내가 앞서 말한 저장 기준은 “그런 사용자 정의 메모리 파일을 운영한다면”의 기준이었고, Codex 내장 기능 설명은 아니었습니다.

## Codex

정정합니다. Codex에도 내장 장기기억이 있습니다. 단일 `memory.md`가 아니라 `~/.codex/memories/` 아래의 생성형 메모리 저장소이며, 이 환경에서 활성화 여부만 안전하게 확인하겠습니다.

## Codex

맞습니다. **Codex에도 Claude의 자동 메모리와 비슷한 기능이 있습니다.** 앞 답변은 틀렸습니다.

다만 단일 `memory.md`가 아니라, Codex가 자동 관리하는 `~/.codex/memories/` 아래의 여러 메모리 파일입니다. 이전 대화의 요약, 장기 사실, 최근 입력, 근거를 저장합니다. 기능적으로는 Claude의 `MEMORY.md` 계열 “온톨로지/장기기억”에 가깝습니다. [공식 Memories 문서](https://learn.chatgpt.com/docs/customization/memories?surface=app)

구분은 이렇습니다.

- `AGENTS.md`: 반드시 지켜야 할 프로젝트 규칙·정책. 항상 적용해야 하는 내용.
- `~/.codex/memories/`: 과거 작업에서 추출한 유용한 맥락. 보조 기억이며, 규칙의 권위는 없음.

Codex는 활성화된 경우에만 적합한 이전 대화에서 기억을 백그라운드로 생성합니다. 짧거나 진행 중인 세션은 건너뛰고, 비밀정보는 생성 과정에서 제거합니다. 기억은 대화 종료 직후가 아니라 유휴 상태가 된 뒤 갱신될 수 있습니다. [공식 동작·저장 위치 안내](https://learn.chatgpt.com/docs/customization/memories?surface=app)

현재 이 환경은 `memories = true` 설정이 없고 `~/.codex/memories/` 폴더도 비어 있어, **로컬 Codex 메모리가 꺼진 상태**입니다. 켜려면 ChatGPT 데스크톱 앱의 **Settings → Personalization → Enable memories** 또는 채팅의 `/memories`를 사용합니다. 활성화 여부와 현재 채팅의 기억 사용·생성 여부도 `/memories`에서 제어합니다.
